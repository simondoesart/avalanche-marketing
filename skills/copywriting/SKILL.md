# Copywriting

## Serve the bank

Read `../../brand/copy-bank.md` (relative to this skill's base directory) and present the relevant section: master lines, onchain finance/institutions, enterprise/consumer, performance & proof, CTAs, formula patterns, and the avoid-list. If the user just wants the list, show it grouped and stop.

## Generate new copy

When asked to write:

1. Load tone guardrails from `../../brand/messaging-framework-PRIVATE.md` (fallback: copy-bank guardrails).
2. Ground any factual claim in `../../brand/avalanche-knowledge.md`; verify technical numbers against live docs (append `.md` to any build.avax.network URL) before using them in external copy.
3. Match the audience lens (institutions / fintech / enterprise / developers / community) and channel (OOH is 7 words max; X post ≤ 280 with a hook in line one; landing page hero = headline + subhead + CTA).
4. Deliver 5–10 options ranked, with a one-line rationale for the top pick. Use the formula patterns (legacy pain → outcome; triads; calm-authority juxtaposition; manifesto cadence).
5. Headline treatments are ALL CAPS (Aeonik Black in design). Note this next to display copy.

Never use avoid-list language. Flag any claim that needs legal/compliance review (yields, comparisons, "never gone down" claims).

New lines that perform well should be added to the copy bank — offer to append them to `copy-bank.md` so the bank grows over time.
