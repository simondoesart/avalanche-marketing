# Social Strategy

Channel-level strategy for Avalanche-owned social, in the Built for Business voice.

## Grounding

Voice: `../../brand/messaging-framework-PRIVATE.md` guardrails. Copy: `../../brand/copy-bank.md`. Visuals: `../../brand/visual-guidelines.md`. Current state: offer to run `/avalanche-social-audit` first if recency matters; check live trends via `/trends-audit` thinking (web search, never memory).

## Channel temperaments (same truth, different temperature)

- **X @avax** — the fast channel. Wry, confident, punchy. News, proof drops, sharp POV on industry moments, builder amplification. Can be playful; never degen.
- **LinkedIn** — the institutional channel. Case studies, exec POVs, partnership stories, hiring/culture. Outcome-led storytelling for decision-makers.
- **YouTube** — the depth channel. Films, explainers, event content, OnChain Finance playlist-style series.
- **Discord/Reddit/Arena** — the community channels. Service, transparency, celebration of builders. Marketing listens more than it posts.

## Content pillar starting framework (adapt per brief)

1. **Proof** — institutional wins, case studies, real usage stats (verify numbers first).
2. **Product & education** — L1s, payments, tokenization explained in outcomes language.
3. **Ecosystem & builders** — amplify what's being built; grants, hackathons, Team1.
4. **Culture & moments** — trends we can credibly join (brand test from /trends-audit), events, Avalanche IRL-style humor: calm amid the avalanche.

## Deliverables

Depending on ask: pillar framework with % mix, 2–4 week content calendar with formats and hooks, format playbook (threads, motion cards in brand style, diptych statics), engagement/community guidelines, and KPIs per channel (engagement quality and share-of-voice over raw follower counts). Draft example posts for each pillar using /copywriting patterns.

Offer output as local file or Google Doc.
