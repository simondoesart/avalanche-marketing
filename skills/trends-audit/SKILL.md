# Trends Audit & Forecast

Surface what's happening now and what's coming, filtered for what Avalanche can credibly join.

## Process

1. **Scan (web search — always live, never memory)** across four lanes:
   - **Culture/social**: platform trends, meme formats, viral moments (last 7–14 days)
   - **Finance/institutional**: tokenization, stablecoins, payments, RWA, regulation news — our home turf
   - **Crypto industry**: competitor announcements, conference season, market narratives
   - **Calendar**: holidays, sports/finance calendar (earnings seasons, Sibos/Money20/20-type events, Avalanche Summit NYC Sep 16–17 2026), seasonal moments 4–8 weeks out
2. **Filter with the brand test.** Avalanche joins a trend only when we can be the most credible system in the room: outcome-led, precise, no forced meme-chasing. Rate each trend: relevance to Built for Business, longevity (spike vs. wave), and risk (see avoid-list in `../../brand/copy-bank.md`).
3. **Forecast.** Project 3–5 upcoming waves for the next 30–90 days with reasoning (what signal → what likely peak moment).
4. **Deliver**: a NOW / NEXT / LATER board — each item with: the trend, the evidence link, the Avalanche angle in one line, suggested format/channel, and effort level. Include 2–3 "do not touch" trends with reasons.

Offer output as local file or Google Doc; offer to set up a recurring weekly trends brief via a scheduled task if the environment supports it.
