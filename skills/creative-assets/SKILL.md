# Creative Assets

Read and present, relative to this skill's base directory:

1. `../../brand/resource-links.md` — public asset links (brand asset Drive folder, web properties, socials).
2. `../../brand/resource-links-PRIVATE.md` — internal links (2026 presentation template, messaging framework doc). Only present these if the file exists; remind the user these links are internal-only and must not be shared externally or posted publicly.
3. Color chart: `../../brand/assets/avalanche-color-chart.png` — show or link it when colors are requested; hex values are in `../../brand/visual-guidelines.md`.

## Answer patterns

- "Logo" → Drive brand assets folder + naming convention (`AVALANCHELOGO_HORIZONTAL_4C_KO` etc.) so they grab the right variant; remind about safe space and approved colorways (red/white/gray/black).
- "Colors" → show the color chart and the key hexes: #E6212F red, #0061E2 blue, #1F1F1F dark bg, #EBF0FA light bg.
- "Fonts" → Aeonik (Black caps for headlines), Aeonik Fono (data/captions), Inter as substitute.
- "Presentation template" → internal Google Slides template link from the PRIVATE file.
- "Where do I put finished work / working files" → this is team-specific; if not yet documented, offer to add the location to `resource-links-PRIVATE.md`.

If an asset category isn't covered, say so and offer to add a link placeholder to the appropriate resource file (PRIVATE file for anything internal).
